
# Creating a Small GIF

Apparently this is quite hard with Adobe Premiere exporter, even in 2026. The best way was;

1. Create the small mp4 with adobe as normal
2. Use [freeconvert.com/mp4-to-gif](https://www.freeconvert.com/convert/mp4-to-gif) to make a .gif
3. Then use [freeconvert.com/giv-compressor](https://www.freeconvert.com/gif-compressor) to compress it even smaller (lose quality)
